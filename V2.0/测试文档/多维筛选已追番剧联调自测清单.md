# 多维筛选已追番剧联调自测清单

## 1. 测试范围

- 默认全量展示与固定排序（`lastWatchAt desc` -> `trackDate desc` -> `id desc`）
- 状态 Tabs 本地过滤（不向后端传 `status`）
- 放映年份/季度筛选
- 开始追番时间段筛选（闭区间）
- 多条件交集筛选

## 2. 环境准备

- 后端：`PersonalBlog-backend` 已启动（`http://localhost:8080`）
- 前端：`PersonalBlog-frontend` 已启动（`http://localhost:5173`）
- 数据准备建议：至少包含 6 部番剧，覆盖不同 `airYear/airSeason/status/trackDate/lastWatchAt`

## 3. 用例清单

### 3.1 首屏默认行为

- 步骤
  - 打开追番页面
- 预期
  - 展示全量追番记录
  - 状态 Tab 默认“全部”
  - 空过滤条件下按 `lastWatchAt desc` 排序，空 `lastWatchAt` 排后

### 3.2 状态 Tabs 本地过滤

- 步骤
  - 依次点击“想看/在看/已看完/全部”
- 预期
  - 卡片数量随状态切换即时变化
  - 不触发后端 `status` 参数请求（可在网络面板确认）

### 3.3 放映年份筛选

- 步骤
  - 选择某个放映年份
- 预期
  - 列表仅显示该年份番剧
  - 季度下拉仅展示该年份实际存在季度

### 3.4 放映季度联动

- 步骤
  - 在已选年份下选择某季度
  - 再切换到另一年份
- 预期
  - 若原季度在新年份无效，自动重置为“全部季度”

### 3.5 开始追番时间段筛选（闭区间）

- 步骤
  - 设置 `trackDateStart` 与 `trackDateEnd`
- 预期
  - 仅保留 `trackDateStart <= trackDate <= trackDateEnd` 的记录
  - 边界日期应被包含

### 3.6 单端点时间筛选

- 步骤
  - 仅设置开始日期
  - 清空后仅设置结束日期
- 预期
  - 仅开始：`trackDate >= start`
  - 仅结束：`trackDate <= end`

### 3.7 时间段非法顺序处理

- 步骤
  - 先选较晚开始日期，再选较早结束日期
- 预期
  - 前端自动调整并提示“开始日期不能晚于结束日期，已自动调整结束日期”

### 3.8 复合筛选交集

- 步骤
  - 同时设置：状态（本地）、放映年份、放映季度、时间段
- 预期
  - 最终结果为交集
  - 计数与空态显示正确

### 3.9 重置筛选

- 步骤
  - 设置多个筛选条件后点击“重置筛选”
- 预期
  - 年份/季度/时间段均恢复默认
  - 状态 Tab 保持当前值（仅重置顶部筛选）

### 3.10 空状态文案

- 步骤
  - 通过组合筛选得到空结果
- 预期
  - 文案为：`当前筛选条件下暂无追番记录`

## 4. 接口核对

- 路径：`GET /api/anime/list`
- 支持参数：`year`、`season`、`status`、`trackDateStart`、`trackDateEnd`
- 当前前端实际调用：仅按需传 `year/season/trackDateStart/trackDateEnd`，不传 `status`

## 5. 回归检查点

- 导入、进度快捷操作、追番时间编辑功能不受影响
- 卡片“开始追番/最近观看”显示正常
- 切换状态 Tabs 时无页面闪烁或异常重排
