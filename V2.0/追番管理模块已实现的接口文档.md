# 追番管理模块 — 已实现接口文档（V1 现状）

> 基于 `AnimeController.java`、`AnimeService.java`、`BangumiDTOs.java`、`AnimeSubject.java`、`AnimeProgress.java` 整理。  
> 前端通过 Vite 代理 `/api` → `http://localhost:8080`。

## 统一响应格式

所有接口返回：

```json
{
  "code": 200,
  "message": "success",
  "data": ...
}
```

错误时：
```json
{
  "code": 500,
  "message": "<可读错误描述>",
  "data": null
}
```

## 1. 搜索 Bangumi 番剧

| 项目 | 内容 |
|------|------|
| 功能 | 根据关键词搜索 Bangumi 番剧 |
| 方法 | `GET` |
| 路径 | `/api/anime/search` |

### Request

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| keyword | Query | String | 是 | 搜索关键词 |

### Response `data`

`List<SubjectItem>`

```json
[
  {
    "id": 456174,
    "name": "xxx",
    "name_cn": "xxx",
    "summary": "...",
    "images": {
      "large": "https://...",
      "common": "https://...",
      "medium": "https://...",
      "small": "https://...",
      "grid": "https://..."
    },
    "eps": 12,
    "date": "2025-01-01"
  }
]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | Bangumi subject ID |
| name | String | 日文/原文名称 |
| name_cn | String | 中文名称（可能为空） |
| summary | String | 简介 |
| images | Images | 尺寸图片集合 |
| eps | int | 总集数 |
| date | String | 首播日期 |

## 2. 导入番剧

| 项目 | 内容 |
|------|------|
| 功能 | 从 Bangumi 导入番剧到本地库并初始化进度 |
| 方法 | `POST` |
| 路径 | `/api/anime/import` |

### Request Body

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| bgmId | int | 是 | Bangumi subject ID |
| airYear | int | 是 | 播出年份 |
| airSeason | int | 是 | 播出季度（1-4） |

```json
{
  "bgmId": 456174,
  "airYear": 2025,
  "airSeason": 1
}
```

### Response `data`

`null`（成功时无返回数据）

### 说明

- 同一事务内写入 `blog_anime_subject` 和 `blog_anime_progress` 两条记录；
- 当前版本重复导入同一 `bgmId` 会报 500 异常，未做幂等处理。

## 3. 获取追番列表

| 项目 | 内容 |
|------|------|
| 功能 | 获取已导入番剧列表（含进度） |
| 方法 | `GET` |
| 路径 | `/api/anime/list` |

### Request

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| year | Query | Integer | 否 | 按播出年份筛选 |
| season | Query | Integer | 否 | 按播出季度筛选（1-4） |

### Response `data`

`List<Map<String, Object>>` — 每个 Map 包含两个 key：

| key | 类型 | 说明 |
|-----|------|------|
| subject | AnimeSubject | 番剧主体信息 |
| progress | AnimeProgress | 追番进度 |

#### AnimeSubject 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 本地主键 ID |
| bgmId | Integer | Bangumi subject ID |
| title | String | 标题 |
| imageUrl | String | 封面图片 URL |
| eps | Integer | 总集数 |
| airYear | Integer | 播出年份 |
| airSeason | Integer | 播出季度（1-4） |
| status | Integer | 追番状态：0=想看，1=在看，2=已完结 |
| createTime | LocalDateTime | 创建时间 |
| updateTime | LocalDateTime | 更新时间 |

#### AnimeProgress 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| animeId | Long | 关联的 subject ID |
| watchedEps | List<Integer> | 已观看集号列表（JSON 存储） |

### 说明

- `year` 和 `season` 均可选，不传则返回全部记录；
- 当前版本无排序能力，无状态筛选能力；
- 返回结构为 Map 而非专用 VO，不利于前端类型推断。

## 4. 切换单集观看状态

| 项目 | 内容 |
|------|------|
| 功能 | 切换指定集数的已看/未看状态 |
| 方法 | `POST` |
| 路径 | `/api/anime/toggle` |

### Request Body

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| animeId | Long | 是 | 本地番剧 ID |
| episodeIndex | Integer | 是 | 集数编号 |

```json
{
  "animeId": 1,
  "episodeIndex": 5
}
```

### Response `data`

`null`

### 说明

- 逻辑为 toggle：已看过则移除，未看过则添加；
- 当前版本无参数范围校验（episodeIndex 未校验是否合法）；
- watchedEps 为 List，由 Service 层手动 add/remove 操作。

---

## 5. 更新追番状态

| 项目 | 内容 |
|------|------|
| 功能 | 修改番剧的追番状态（想看/在看/已完结） |
| 方法 | `PUT` |
| 路径 | `/api/anime/status` |

### Request Body

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| animeId | Long | 是 | 本地番剧 ID |
| status | Integer | 是 | 目标状态：0=想看，1=在看，2=已完结 |

```json
{
  "animeId": 1,
  "status": 2
}
```

### Response `data`

`null`

### 说明

- 当前版本仅做简单字段更新，无状态与进度联动规则；
- 未校验状态值是否合法（非 0/1/2 时行为未定义）。

## 附录：数据实体概览

### blog_anime_subject

| 列名 | 类型 | 说明 |
|------|------|------|
| id | BIGINT (PK, 自增) | 本地主键 |
| bgm_id | INT | Bangumi subject ID |
| title | VARCHAR | 标题 |
| image_url | VARCHAR | 封面图 URL |
| eps | INT | 总集数 |
| air_year | INT | 播出年份 |
| air_season | INT | 播出季度 |
| status | INT | 追番状态 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

### blog_anime_progress

| 列名 | 类型 | 说明 |
|------|------|------|
| anime_id | BIGINT (PK) | 关联 subject 的 id |
| watched_eps | JSON | 已看集号列表 |
