# PersonalBlog V2.0 追番模块开发进度安排

## 任务概览与分支对应表

| 序号 | 需求项名称 | 核心功能点 | 对应特性分支 |
| :--- | :--- | :--- | :--- |
| 1 | 追番状态切换功能与追番时间字段完善 | 数据库变更、追番状态自动切换、数据库增加追番时间字段| `feature/20260321_anime_progress_auto_status_add_track_date_field` |
| 2 | 导入幂等性校验与重复提示 | 重复导入更新、前端“已存在”提示                       | `feature/20260321_anime_idempotent_import` |
| 3 | 追番进度快捷操作 | “看到第 N 集”、“一键看完”、“重置进度”接口及 UI | `feature/20260321_anime_quick_progress` |
| 4 | 自定义开始追番时间 | 用户能够更改开始追番时间，导入的时候能够选择追番时间，用户不设置的话，默认为导入时间。追番列表每个卡片展示追番时间 | `feature/20260321_anime_custom_track_date` |
| 5 | 多维度筛选已追番剧 | 按追番年份/季度、放映季度、状态筛选；按更新时间排序 | `feature/20260322_anime_filter_sorting` |
| 6 | 搜索场景语义化异常反馈 | 区分“无结果”与“API 请求失败”、前端差异化 UI 提示 | `feature/20260322_anime_search_feedback` |
| 7 | 删除追番记录 | 用户能够对所追的番剧 | `feature/20260322_anime_delete_track_anime_record` |
