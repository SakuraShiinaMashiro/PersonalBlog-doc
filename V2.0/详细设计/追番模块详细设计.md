# PersonalBlog V2.0 追番模块详细设计

## 1. 概念定义

### 1.1 核心概念区分

| 概念 | 字段 | 含义 | 数据来源 |
|------|------|------|----------|
| **追番时间** | `track_date` | 用户开始追这部番的时间 | 默认导入时间，用户可手动修改 |
| **放映季度** | `air_year` + `air_season` | 番剧首播的年份和季度 | Bangumi API 的 `date` 字段 |

### 1.2 季度换算规则

```java
// 月份 → 季度
month 1-3   → 冬季 (1)
month 4-6   → 春季 (2)
month 7-9   → 夏季 (3)
month 10-12 → 秋季 (4)
```

### 1.3 筛选维度说明

| 筛选类型 | 筛选字段 | 场景示例 |
|----------|----------|----------|
| **按追番时间** | `track_date` | "我2026冬季（1-3月）追了哪些番" |
| **按放映季度** | `air_year` + `air_season` | "2026年春季有哪些新番" |

### 3.4 Service 层设计

**季度换算工具方法**
```java
public class SeasonUtils {
    /**
     * 根据月份计算季度
     * @param month 月份 (1-12)
     * @return 季度 (1:冬, 2:春, 3:夏, 4:秋)
     */
    public static int getSeasonByMonth(int month) {
        if (month >= 1 && month <= 3) return 1; // 冬
        if (month >= 4 && month <= 6) return 2; // 春
        if (month >= 7 && month <= 9) return 3; // 夏
        return 4; // 秋 (10-12)
    }
    
    /**
     * 根据日期计算季度
     * @param date 日期
     * @return 季度
     */
    public static int getSeason(LocalDate date) {
        return getSeasonByMonth(date.getMonthValue());
    }
    
    /**
     * 获取季度名称
     */
    public static String getSeasonName(int season) {
        return switch (season) {
            case 1 -> "冬";
            case 2 -> "春";
            case 3 -> "夏";
            case 4 -> "秋";
            default -> "";
        };
    }
}
```

**列表查询逻辑**
```java
@Override
public List<AnimeListItemVO> getAnimeListWithProgress(
        Integer year, Integer season, 
        Integer trackYear, Integer trackSeason, 
        Integer status,
        String sortBy, String sortOrder) {
    
    LambdaQueryWrapper<AnimeSubject> queryWrapper = new LambdaQueryWrapper<>();
    
    // 按放映季度筛选
    if (year != null) {
        queryWrapper.eq(AnimeSubject::getAirYear, year);
    }
    if (season != null) {
        queryWrapper.eq(AnimeSubject::getAirSeason, season);
    }
    
    // 按追番时间筛选
    if (trackYear != null) {
        queryWrapper.apply("YEAR(track_date) = {0}", trackYear);
    }
    if (trackSeason != null) {
        // 季度范围：1=1-3月, 2=4-6月, 3=7-9月, 4=10-12月
        int startMonth = (trackSeason - 1) * 3 + 1;
        int endMonth = trackSeason * 3;
        queryWrapper.apply("MONTH(track_date) BETWEEN {0} AND {1}", startMonth, endMonth);
    }
    
    // 按状态筛选
    if (status != null) {
        queryWrapper.eq(AnimeSubject::getStatus, status);
    }
    
    // 排序
    if ("track_date".equals(sortBy)) {
        queryWrapper.orderBy(true, "asc".equals(sortOrder), AnimeSubject::getTrackDate);
    } else {
        queryWrapper.orderByDesc(AnimeSubject::getCreateTime);
    }
    
    List<AnimeSubject> subjects = subjectMapper.selectList(queryWrapper);
    
    return subjects.stream().map(s -> {
        AnimeListItemVO vo = new AnimeListItemVO();
        vo.setSubject(s);
        vo.setProgress(progressMapper.selectById(s.getId()));
        if (s.getTrackDate() != null) {
            vo.setTrackYear(s.getTrackDate().getYear());
            vo.setTrackSeason(SeasonUtils.getSeason(s.getTrackDate()));
        }
        return vo;
    }).collect(Collectors.toList());
}
```

**导入逻辑增强**
```java
@Override
@Transactional(rollbackFor = Exception.class)
public ImportResult importAnime(Integer bgmId, LocalDate trackDate) {
    // 幂等检查
    AnimeSubject existing = subjectMapper.selectOne(
        new LambdaQueryWrapper<AnimeSubject>()
            .eq(AnimeSubject::getBgmId, bgmId)
    );
    
    if (existing != null) {
        return ImportResult.duplicate(existing);
    }
    
    // 从 Bangumi API 获取番剧信息
    BangumiSubject subject = bangumiClient.getSubject(bgmId);
    if (subject == null) {
        throw new BusinessException("无法获取番剧信息");
    }
    
    // 从首播日期提取放映季度
    LocalDate airDate = parseAirDate(subject.getDate());
    Integer airYear = airDate != null ? airDate.getYear() : null;
    Integer airSeason = airDate != null ? SeasonUtils.getSeason(airDate) : null;
    
    // 保存主体
    AnimeSubject animeSubject = new AnimeSubject();
    animeSubject.setBgmId(bgmId);
    animeSubject.setTitle(subject.getNameCn() != null ? subject.getNameCn() : subject.getName());
    animeSubject.setImageUrl(subject.getImages().getLarge());
    animeSubject.setEps(subject.getEpsCount());
    animeSubject.setAirYear(airYear);
    animeSubject.setAirSeason(airSeason);
    animeSubject.setStatus(0); // 默认"想看"
    animeSubject.setTrackDate(trackDate != null ? trackDate : LocalDate.now());
    subjectMapper.insert(animeSubject);
    
    // 创建进度记录
    AnimeProgress progress = new AnimeProgress();
    progress.setAnimeId(animeSubject.getId());
    progress.setWatchedEps(new ArrayList<>());
    progressMapper.insert(progress);
    
    return ImportResult.success(animeSubject);
}
```

**快捷进度更新逻辑**
```java
@Override
@Transactional(rollbackFor = Exception.class)
public AnimeProgress setProgressTo(Long animeId, Integer episode) {
    AnimeSubject subject = subjectMapper.selectById(animeId);
    if (subject == null) {
        throw new BusinessException("番剧不存在");
    }
    
    // 有效性校验
    if (episode < 1 || (subject.getEps() != null && episode > subject.getEps())) {
        throw new BusinessException("集数超出范围");
    }
    
    AnimeProgress progress = progressMapper.selectById(animeId);
    // 生成 1 到 episode 的有序列表
    List<Integer> watchedEps = IntStream.rangeClosed(1, episode)
        .boxed()
        .collect(Collectors.toList());
    progress.setWatchedEps(watchedEps);
    progressMapper.updateById(progress);
    
    return progress;
}

@Override
@Transactional(rollbackFor = Exception.class)
public AnimeProgress completeAnime(Long animeId) {
    AnimeSubject subject = subjectMapper.selectById(animeId);
    if (subject == null) {
        throw new BusinessException("番剧不存在");
    }
    
    AnimeProgress progress = progressMapper.selectById(animeId);
    if (subject.getEps() != null && subject.getEps() > 0) {
        List<Integer> watchedEps = IntStream.rangeClosed(1, subject.getEps())
            .boxed()
            .collect(Collectors.toList());
        progress.setWatchedEps(watchedEps);
        progressMapper.updateById(progress);
    }
    
    return progress;
}

@Override
@Transactional(rollbackFor = Exception.class)
public AnimeProgress resetProgress(Long animeId) {
    AnimeProgress progress = progressMapper.selectById(animeId);
    if (progress == null) {
        throw new BusinessException("进度记录不存在");
    }
    
    progress.setWatchedEps(new ArrayList<>());
    progressMapper.updateById(progress);
    
    return progress;
}
```
