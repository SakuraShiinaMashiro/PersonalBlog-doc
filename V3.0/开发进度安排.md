# PersonalBlog V3.0 开发进度安排

## 任务概览与分支对应表

| 序号 | 需求项名称 | 核心功能点 | 对应特性分支 |
| :--- | :--- | :--- | :--- |
| 1 | 用户认证与权限校验 | 仅博主可增删改、密钥导入、账号密码登录、邮箱二次校验与改密。普通游客用户只支持第三方登录 | `feature/20260331_auth_acl_oauth_key_email` |
| 2 | 首页博主信息数据库化 | 首页头像与名称从数据库读取 | `feature/20260331_home_owner_profile_from_db` |
| 3 | 对象存储服务 | MinIO 存放图片/视频/附件 | `feature/20260331_note_object_storage_minio` |
| 4 | 笔记分类与子类 | 三大类下细分子类创建与选择 | `feature/20260331_note_category_subcategory` |
| 5 | Tag 管理增强 | 写文章选已有或新建 Tag | `feature/20260331_note_tag_manage` |
| 6 | 笔记编辑与可见性 | 删除/修改、仅自己可见、草稿箱管理 | `feature/20260331_note_edit_visibility_draft` |
| 7 | Markdown 笔记导入 | 支持直接导入 Markdown | `feature/20260331_note_import_markdown` |
| 8 | 笔记阅读信息 | 最后修改时间、阅读时长、字数统计 | `feature/20260331_note_read_meta` |
| 9 | 阅读进度与目录 | 阅读进度显示、阅读/编辑左侧目录 | `feature/20260331_note_read_progress_toc` |
| 10 | 分类页布局与搜索 | 左侧子类/中间列表/右侧搜索与 Tag 统计、搜索弹窗复用、封面图策略 | `feature/20260331_note_category_page_layout` |
