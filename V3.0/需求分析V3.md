# PersonalBlog V3.0 需求分析文档 (认证与笔记增强)

## 1. 背景与目标
V1.0 和 V2.0 已经完成了博客的基础搭建与追番模块的精细化。V3.0 的核心目标是**建立安全体系**，并显著提升内容创作（写笔记）与内容阅读（看详情）的交互体验。

---

## 2. 核心模块需求

### 2.1 个人认证模块 (Auth Module)
*   **目标**: 保护系统资源，识别管理员身份，为未来评论系统铺路。
*   **功能点**:
    *   **单用户管理员体系**: 支持通过用户名/密码登录，并在后端签发 JWT。
    *   **接口权限加固**: 对所有非 GET 接口（如文章发布、番剧导入、图片上传等）实施强制鉴权，返回 401 或业务错误码。
    *   **未来扩展支持**: 用户表需预留 `openid` 字段，以支持 V4.0 版本接入第三方（GitHub/Bilibili 等）OAuth2 登录进行评论。
*   **技术选型**: **Sa-Token** (轻量高效，原生支持 JWT 与 OAuth2 扩展)。

### 2.2 笔记模块完善 (Note Perfection)

#### A. 全局检索
*   **功能**: 支持跨标题、摘要、正文的全局关键字模糊搜索。
*   **性能**: 确保在千级数据量下搜索响应在 200ms 以内（不含网络）。

#### B. 写笔记页面 (Write View) 优化
*   **MinIO 云存储**: 集成 MinIO 对象存储，实现图片的快速上传、持久化存储与备份。
*   **交互增强**: 
    *   支持图片拖拽/剪贴板直接上传，自动插入 Markdown 链接。
    *   实现**自动保存**机制，定期将草稿缓存至后端或本地，防止断电等意外导致的内容丢失。
    *   **标签辅助**: 实时推荐已有标签，保持标签体系整洁。
    *   **沉浸模式**: 支持全屏编辑、双栏实时预览与代码块主题选择。

#### C. 笔记详情页 (Detail View) 优化
*   **智能目录 (TOC)**: 动态解析 Markdown 标题，生成可点击跳转的侧边栏目录。
*   **阅读体验**:
    *   顶部展示滚动进度条。
    *   文章内图片支持点击放大（灯箱效果）。
    *   增加“字数统计”与“预计阅读时间”。
*   **代码优化**: 支持多种语言高亮，并提供一键“复制代码”功能。
*   **上下文关联**: 底部提供“上一篇”与“下一篇”的平滑跳转。

---

## 3. 技术路线 (Analysis Phase)
*   **存储**: **MinIO** (私有化部署，兼容 S3)。
*   **后端**: Java 17, Spring Boot 3.5, Sa-Token, MyBatis Plus。
*   **前端**: Vue 3, Pinia (管理认证状态), Axios (请求拦截器携带 Token), Viewer.js (图片查看)。

---

## 4. 验收指标
1. 管理员能且仅能管理员通过 `/login` 后进行增删改操作。
2. 所有笔记图片均存储在 MinIO 中，不再依赖外部不稳定外链或 Base64。
3. 搜索框能实时且准确地反馈结果。
4. 详情页具备自动生成的层级目录，且代码块可直接复制。
